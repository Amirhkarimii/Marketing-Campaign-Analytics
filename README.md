# Marketing-Campaign-Analytics
## Campaign Performance Dashboard
This project analyzes marketing campaign performance using Excel and focuses on identifying high- and low-performing campaigns based on key performance indicators. 
### Key KPIs 
- Revenue
- Spend
- Profit
- ROAS 
- CTR 
- Conversion Rate
- CPC
- CPA
- ### Dashboard
The dashboard provides a visual overview of campaign performance and highlights the Top 10 campaigns based on Profit.
- ### Tools
- Microsoft Excel 
- PivotTables 
- PivotCharts 
- Excel Formulas 
- Data Cleaning
- Data Visualization
- ### Project Objective
The objective of this project is to analyze campaign-level data, calculate relevant marketing KPIs, and create an interactive dashboard that supports performance analysis and comparison.
